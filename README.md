# interview_practice_react
A Selection of interview style apps written with react.

These currently include
1. Todo app - a basic application to write todos which are stored in local storage, the todos are displayed in a list and can be clicked on and crossed out when complete.
2. Calculator App - a basic arithmetic calculator
3. Expenses Tracker App - this app allows you to set a budget, and add expenses, a list of the expenses is shown with indication of whether these are in budget or not, expenses can be cleared and remaining budget is updated to reflect what funds the user is left with after that expense is cleared
4. Tip Calculator - a simple tip calculator where you enter in your bill and a table of tip percentages is returned with amount and total amount incluidng tip.
5. 5 Day Weather app - this app uses the openweather api to return 5 day (3 hourly) weather data based on the users input location.
